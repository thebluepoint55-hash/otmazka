# Отмазка · Бюро объяснительных

Шуточный генератор отмазок для начальника. Берёте штамп, печатаете объяснительную на машинке, расписываетесь и отправляете шефу. Прокатит или нет — как повезёт.

**Открыть:** https://thebluepoint55-hash.github.io/otmazka/

Лучше всего смотреть на компьютере с экраном от 1280 px. Подсказки на экране ведут по шагам.

## Горячие клавиши

| Клавиша | Что делает |
|---|---|
| `R` | Начать заново |
| `1` / `2` / `3` | Главная / Оплата / Генератор |
| `4` | Сразу отправить шефу |
| `H` | Спрятать подсказки |
| `M` | Звук вкл/выкл |
| `Esc` | Положить штамп обратно |

Пока машинка печатает, все клавиши печатают; клавиши выше в это время работают с `Shift`.

Оплата ненастоящая: карта тестовая, ничего не вводится, не списывается и никуда не отправляется. Все совпадения с реальными начальниками случайны.
